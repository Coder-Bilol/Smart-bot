# ✨ Smart-bot: Твой уютный ИИ-собеседник

Добро пожаловать в репозиторий **Smart-bot** — умного Telegram-бота, который умеет не просто отвечать на команды, а по-настоящему вливаться в разговор и следить за порядком в твоем уютном сообществе.

---

## 🍃 О проекте

Этот бот создан для тех, кто хочет оживить свои чаты. Он работает на базе передовых LLM (через OpenRouter) и обладает уникальным характером, который ты можешь настроить сам.

### Что он умеет:
*   **💬 Живое общение**: Бот не ждет упоминаний. Он слушает контекст и вступает в диалог тогда, когда это уместно.
*   **🎭 Смена масок**: Сегодня он — строгий ассистент, завтра — шутливый бармен. Настраивай роль и цели прямо на лету.
*   **🛡 Умная модерация**: Больше никаких скучных фильтров по словам. Бот понимает смысл сообщения и мягко (или не очень) пресекает оскорбления и спам.
*   **🏘 Каждому свой дом**: Бот помнит настройки и «серые списки» для каждой группы отдельно. В одном чате он может быть любителем котиков, в другом — серьезным программистом.

## 🛠 Как запустить этого парня?

Чтобы бот ожил в твоем терминале, нужно всего несколько шагов:

1.  **Создай окружение**:
    ```bash
    python -m venv venv
    source venv/bin/activate  # На Windows: .\venv\Scripts\Activate.ps1
    ```
2.  **Установи зависимости**:
    ```bash
    pip install -r requirements.txt
    ```
3.  **Настрой секреты**:
    Создай файл `.env` в корневой папке и добавь туда:
    ```env
    TG_TOKEN=твой_токен_от_BotFather
    OPENROUTER_KEY_ZAI=твой_ключ_от_OpenRouter
    # И другие ключи из config.py для разных моделей
    ```
4.  **Зажигай!**:
    ```bash
    python src/main.py
    ```

## 📜 Краткая шпаргалка по командам

*   `/help` — Твой верный путеводитель по всем возможностям.
*   `/startconv` — Разбудить бота в чате (только для админов).
*   `/groupabout` — Рассказать боту, о чем этот чат, чтобы он знал, кого ругать, а кого хвалить.
*   `/graylist` — Посмотреть список тех, кто немного заигрался (доступно всем!).
*   `/model` — Выбрать "мозг" для бота из списка доступных нейросетей.
