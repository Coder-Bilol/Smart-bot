# Краткое описание проекта Smart Bot

## 1. Обзор
Smart Bot — это продвинутый Telegram-бот, разработанный для участия в групповых чатах в качестве интеллектуального агента. В отличие от простых командных ботов, Smart Bot сохраняет контекст, понимает нити разговора и естественно участвует в дискуссиях, используя большие языковые модели (LLM) через OpenRouter.

## 2. Ключевые возможности
- **Режим разговора**: При активации (`/startconv`) бот слушает сообщения и отвечает во время пауз или при прямом обращении.
- **Динамический контекст**: Хранит историю последних 50 сообщений для понимания хода беседы.
- **Настраиваемая личность**: Администраторы могут устанавливать пользовательские роли (`/role`) и цели (`/goal`) для формирования поведения бота (например, "Саркастичный разработчик", "Полезный помощник").
- **Выбор модели**: Поддержка переключения между различными LLM (например, Z.ai GLM, Qwen, Kimi) через команду `/model`.
- **Умные задержки**: Использует динамические таймеры для естественных ответов во время пауз, но отвечает мгновенно, если ответили на его сообщение.
- **Сохранение данных**: Настройки чатов и история хранятся в SQLite, обеспечивая непрерывность работы после перезапуска.

## 3. Стек технологий
- **Язык**: Python 3.10+
- **Фреймворк**: [aiogram 3.x](https://docs.aiogram.dev/) (Асинхронный Telegram Bot API)
- **База данных**: SQLite (через `aiosqlite`)
- **Провайдер LLM**: [OpenRouter](https://openrouter.ai/) (доступ через Python SDK `openai`)
- **Конфигурация**: Файл `.env` для секретов и настроек.

## 4. Архитектура
- **Точка входа**: `src/main.py` инициализирует бота, базу данных и роутеры.
- **Управление состоянием**: Гибридный подход:
  - **Постоянное**: База данных (`bot_database.db`) хранит настройки чатов (роль, цель, модель, статус) и логи сообщений.
  - **Временное**: Словарь в оперативной памяти (`active_chats`) отслеживает активные таймеры и флаги "ожидания пользователя".
- **Обработчики (Handlers)**:
  - `admin.py`: Управляет командами настройки (`/role`, `/goal`, `/timeout`, `/model`).
  - `chat.py`: Обрабатывает поток сообщений, активацию разговора и логику таймеров.

## 5. Быстрый старт
1.  **Клонируйте репозиторий**.
2.  **Установите зависимости**:
    ```bash
    pip install -r requirements.txt
    ```
3.  **Настройте окружение**:
    Создайте файл `.env` на основе следующего шаблона:
    ```env
    TG_TOKEN=ваш_токен_telegram_бота
    RESPONSE_DELAY=5
    OPENROUTER_KEY_ZAI=ваш_ключ_zai
    OPENROUTER_KEY_QWEN=ваш_ключ_qwen
    OPENROUTER_KEY_KIMI=ваш_ключ_kimi
    ```
4.  **Запустите бота**:
    ```bash
    python src/main.py
    ```
