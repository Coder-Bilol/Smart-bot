# Smart Bot (AI Powered)

Этот проект представляет собой умного Telegram-бота, разработанного на Python с использованием библиотеки `aiogram`: бот интегрирован с нейросетью (через API VoidAI/Gemini) для ведения осмысленных диалогов.

## Функционал

*   **Умный диалог**: Бот может поддерживать беседу, запоминая контекст (историю сообщений).
*   **Режим разговора**: Команды `/startconv` и `/stopconv` позволяют включать и выключать режим общения с нейросетью.
*   **Обработка эмодзи**: Если сообщение состоит только из эмодзи, бот отвечает забавной фразой.
*   **Имитация человека**: Бот показывает статус "печатает" перед отправкой ответа.

## Установка и запуск

Для запуска бота вам потребуется Python 3.9+ и ключи API.

### 1. Клонирование репозитория

```bash
git clone https://github.com/ваш_пользователь/Smart-bot.git
cd Smart-bot
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
# Windows
venv\Scripts\activate
# Linux/macOS
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте файл `.env` в корне проекта и добавьте следующие переменные:

```env
TG_TOKEN=ваш_телеграм_токен
VOIDAI_API_KEY=ваш_ключ_voidai
VOIDAI_MODEL=gemini-2.5-flash  # Опционально, по умолчанию gemini-2.5-flash
RESPONSE_DELAY=5               # Опционально, задержка ответа в секундах
```

### 5. Запуск бота

```bash
python src/main.py
```

## Команды

*   `/start` - Приветствие.
*   `/startconv` - Начать диалог с нейросетью.
*   `/stopconv` - Закончить диалог.

## Структура проекта

*   `src/main.py`: Точка входа.
*   `src/bot_handlers.py`: Логика обработки команд.
*   `src/api_client.py`: Клиент для работы с API нейросети.
*   `src/config.py`: Конфигурация.
