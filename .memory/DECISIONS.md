# Decisions (ADR)

## ADR-001: Migration to OpenRouter
- **Status**: Accepted
- **Date**: 2025-12-16
- **Context**: VoidAI API стал недоступен/нестабилен.
- **Decision**: Использовать OpenRouter как прокси к различным LLM.
- **Consequences**:
    - Необходимо управление API ключами для разных моделей.
    - Изменение `api_client.py`.

## ADR-003: Neural Network Chat Moderation
- **Status**: Proposed
- **Date**: 2025-12-17
- **Context**: Необходимо обеспечить модерацию пользовательского контента в чатах для предотвращения нежелательного или вредоносного поведения.
- **Decision**: Интегрировать нейросетевую модерацию для анализа и фильтрации сообщений.
- **Consequences**:
    - Дополнительные затраты на API модерации или вычислительные ресурсы.
    - Возможность ложных срабатываний (false positives) или пропусков (false negatives).
    - Усложнение архитектуры системы.

## ADR-002: Hybrid State Storage
- **Status**: Accepted
- **Date**: 2025-12-01
- **Context**: Необходимо сохранять настройки чатов между перезапусками, но таймеры и дебаунс логику держать в памяти для быстродействия.
- **Decision**: 
    - `SQLite`: Настройки (роль, цель, модель), История сообщений.
    - `Memory (Dict)`: Активные объекты таймеров (`asyncio.TimerHandle`), флаги ожидания.
- **Consequences**: При перезапуске таймеры сбрасываются (не критично), но настройки сохраняются.
